- **The Linux AppImage adds Kontena to your application menu the first time you start it.** It writes
  a menu entry to `~/.local/share/applications` and the icon to `~/.local/share/icons`, so you no
  longer need AppImageLauncher or a hand-written `.desktop` file. If you move the AppImage, the entry
  follows on the next start; an entry you edited yourself is left alone.
