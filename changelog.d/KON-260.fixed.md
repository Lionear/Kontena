- **A remote engine over SSH can now connect to a host for the first time.** Kontena connects without
  a terminal attached, so ssh could not ask whether an unfamiliar host was the right one — it simply
  refused, and every host Kontena had not connected to before was every host. It now shows the host's
  fingerprint and asks. Confirming stores it the same way ssh does, so a host trusted here is trusted
  from your terminal too.
- **A host key that *changed* is still refused, and says so.** That is either a rebuilt machine or a
  connection being intercepted, and Kontena will not offer a button that makes the difference go away.
